## Getting Started

Follow these steps to get a local copy up and running.

### Prerequisites

* **Rust & Cargo**
  ```sh
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
* **Nix** (Optional, with flakes enabled)
  ```sh
  curl --proto '=https' --tlsv1.2 -sSf https://nixos.org/nix/install | sh
  ```

### Building & Running

Clone the repository first:
```sh
git clone https://github.com/vinnovateit/repo_name.git
cd repo_name
```

#### Option 1: Using Cargo

* Build debug binary:
  ```sh
  cargo build
  ```
* Build optimized release binary:
  ```sh
  cargo build --release
  ```
* Run the project:
  ```sh
  cargo run
  ```
* Run tests:
  ```sh
  cargo test
  ```

#### Option 2: Using Nix

* Build package:
  ```sh
  nix build
  ```
* Run executable directly:
  ```sh
  nix run
  ```
* Enter development shell with all dependencies:
  ```sh
  nix develop
  ```
